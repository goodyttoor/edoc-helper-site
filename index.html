eDoc Helper

ผู้ช่วยอ่านอย่างเดียวสำหรับ CMU e-Document v3 — ค้นหา กรอง จัดแฟ้ม และติดตามหนังสือเข้าได้เร็วขึ้น ข้อมูลอยู่ในเครื่องของคุณ

ติดตั้งย้ายจากรุ่นทดสอบความเป็นส่วนตัว

ติดตั้ง

ติดตั้งจาก Chrome Web Store

  1. เปิดลิงก์ด้านบนใน Google Chrome หรือ Microsoft Edge แล้วกด เพิ่มลงใน Chrome (Edge: กด อนุญาตส่วนขยายจากร้านค้าอื่น ก่อนหนึ่งครั้ง)
  2. เปิด eDoc และเข้าสู่ระบบตามปกติ — ตัวช่วยจะแสดงในหน้าหนังสือเข้า และพาตั้งค่าเริ่มต้นสั้น ๆ

รุ่นใหม่อัปเดตให้อัตโนมัติ ไม่ต้องทำอะไร

ย้ายจากรุ่นทดสอบ (Load unpacked)

  1. ในรุ่นเดิม: กดไอคอน eDoc Helper → ⚙ → สำรองแฟ้ม สถานะ และบันทึก → ส่งออก (ได้ไฟล์ .json)
  2. ลบรุ่นเดิมที่ chrome://extensions
  3. ติดตั้งจากลิงก์ด้านบน แล้วกด ⚙ → นำเข้า ไฟล์ .json นั้น

รุ่นจาก Web Store เป็นส่วนขยายคนละตัวกับรุ่นทดสอบ ข้อมูลในเครื่องจึงไม่ย้ายตามเอง

นโยบายความเป็นส่วนตัว

ส่วนขยายทำอะไร

eDoc Helper อ่านหนังสือในกล่อง eDoc ของคุณ (edoc.cmu.ac.th) โดยใช้การเข้าสู่ระบบ eDoc ของคุณเอง เพื่อแสดง ค้นหา กรอง และจัดระเบียบให้ใช้งานง่ายขึ้น อ่านอย่างเดียว — ไม่แก้ไข ไม่ส่ง และไม่กดปุ่มใด ๆ ใน eDoc แทนคุณ

ข้อมูลที่ใช้ และเก็บที่ไหน

  • รายการและรายละเอียดหนังสือของคุณ จาก eDoc — เก็บสำเนาไว้ในเบราว์เซอร์ของคุณ (IndexedDB) เพื่อแสดงได้ทันที แยกตามผู้ใช้ eDoc
  • สถานะ แฟ้ม บันทึก และการตั้งค่าของคุณ — เก็บในเบราว์เซอร์ของคุณเท่านั้น
  • การเข้าสู่ระบบ eDoc — ใช้จากคำขอของหน้า eDoc เอง เก็บไว้ในหน่วยความจำขณะใช้งานเท่านั้น ไม่บันทึกลงเครื่อง

ข้อมูลไปที่ไหน

ไม่มีเซิร์ฟเวอร์ของส่วนขยาย ข้อมูลไม่ถูกส่งไปที่ใดนอกจากระบบของ eDoc เอง (edoc.cmu.ac.th, api.cmu.ac.th และที่เก็บไฟล์แนบของ eDoc) ไม่มีการขาย แบ่งปัน วิเคราะห์ หรือติดตามการใช้งาน

ลบข้อมูล

กด ⚙ ในแผงด้านข้าง → ล้างข้อมูล หรือลบส่วนขยายออก — ข้อมูลทั้งหมดในเครื่องจะถูกลบ

ใช้เครื่องร่วมกัน

ข้อมูลแยกตามผู้ใช้ eDoc แต่ไม่ได้เข้ารหัส ควรใช้ Chrome profile หรือบัญชี Windows แยกต่อคน
